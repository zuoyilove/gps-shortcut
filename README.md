The GPS's one-line excuse for sending the driver down the wrong road: it blamed the map, the lake, and the driver's brand-new waterfront property — smug, defensive, and entirely the map's fault.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
